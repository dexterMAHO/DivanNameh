# گنجینهٔ فارسی

هر سطر دیتاست `JSONL.gz` یک EPUB از فهرست کتابخانهٔ گنجور است. فیلد `entries` ترتیب و رابطهٔ بخش‌ها و آثار را از فهرست NCX نگه می‌دارد. شناسه‌های `cat…` و `poem-…` از خود EPUB می‌آیند. برای هر اثر، پیوند گنجور و در نسخه‌های قابل بازنشر، پاراگراف‌های متن ذخیره می‌شوند. متن و فهرست آثار از کتابخانهٔ شخصی کاربران جدا هستند.

پس از دریافت فهرست HTML و EPUBها، دیتاست را بسازید و پس از اعمال مایگریشن، وارد کنید.

```sh
python scripts/export_ganjoor.py exports/ganjoor/catalogue.html exports/ganjoor/epubs exports/ganjoor/treasury.jsonl.gz
python manage.py migrate
python manage.py import_treasury exports/ganjoor/treasury.jsonl.gz
```

برای ورود به Neon از اتصال مستقیم و محیط تنظیم‌شده برای دیتابیس مقصد استفاده کنید. واردکننده هر کتاب را در یک تراکنش ذخیره می‌کند و در اجرای مجدد، کتاب‌هایی را که داده‌شان همان است رد می‌کند. گزینهٔ `--allow-incomplete` برای فایل‌های دردسترس‌نبوده یک رکورد همراه با پیوند منبع می‌سازد و کتاب‌های قبلاً واردشده را با آن جایگزین نمی‌کند.

فهرست رسمی گنجور رایگان است. وضعیت بازنشر متن باید جداگانه بررسی شود. فهرست نسخه‌های قابل بازنشر در `PUBLISHABLE_EDITIONS` نگهداری می‌شود و فعلاً نسخه‌های حافظ و سعدی را شامل می‌شود. برای نسخه‌های دیگر، گنجینه عنوان، دسته‌بندی و پیوند گنجور را نمایش می‌دهد.
