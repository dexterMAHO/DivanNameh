# گزارش آزمون بازطراحی فرانت‌اند

مرجع طراحی: بستهٔ `divannameh-miniature-final`. سند طراحی: `DESIGN.md`.

## ۱. آزمون واحد جنگو

```bash
DJANGO_SETTINGS_MODULE=config.settings_development DJANGO_READ_DOTENV=false \
DATABASE_URL="sqlite:///$(mktemp -d)/test.sqlite3" .venv/bin/python manage.py test --noinput
```

**۹۰ آزمون، همه موفق.**

دو ادعا در آزمون‌ها به متنِ بازنویسی‌شدهٔ همان حالت به‌روز شد (متن عوض شد، رفتار نه):

- `poetry/tests/test_app.py` — حالت «کارتی برای همین حالا آماده نیست» در صفحهٔ مرور.
- `poetry/tests/test_treasury.py` — حالت خالیِ کشف شعر از دفتر شخصی.

## ۲. آزمون مرورگر پروژه

```bash
PYTHON=.venv/bin/python CHROME_BINARY=google-chrome node scripts/check_browser.mjs
```

**موفق.** این آزمون پذیرشِ خودِ پروژه است و موارد زیر را می‌سنجد:

| موضوع | نتیجه |
|---|---|
| اسکرول افقی در ۲۳ مسیر × ۸ عرض (۳۲۰/۳۶۰/۳۹۰/۷۶۸/۱۰۲۴/۱۱۰۱/۱۲۸۰/۱۴۴۰) | هیچ صفحه‌ای ندارد |
| خطای بررسی‌نشدهٔ JavaScript | صفر |
| کنتراست ۴ پالت × روشن و تاریک | متن و کنش ≥ ۴٫۵:۱، فوکوس و خط کنترل ≥ ۳:۱ |
| کنتراست رنگ تأکیدیِ دلخواه پس از اصلاح خودکار | ≥ ۴٫۵:۱ در هر ۸ ترکیب |
| اندازهٔ متن شعر در ۳۲۰ پیکسل | ۲۲ پیکسل، بدون برش افقی، بیت اول بالای خط افق |

## ۳. آزمون مسیرها

۲۹ مسیرِ کاربرِ واردشده و ۷ مسیرِ مهمان با `django.test.Client` فراخوانی شدند؛
هیچ خطای قالب یا نما رخ نداد.

## ۴. بازبینی ایستا

- **کنتراست توکن‌ها:** هر ۱۲ بلوک پالت در `tokens.css` به‌صورت برنامه‌ای
  سنجیده شد (متن روی زمینه/سطح/سطح تیره، متن روی شستشوها، متن روی پنل تیره).
- **پوششِ شیوه‌نامه:** برای هر قالب، هر کلاسِ به‌کاررفته در یک شیوه‌نامه‌ای
  تعریف شده است که همان صفحه بارگذاری می‌کند (با دنبال‌کردن `extends` و
  `include`). دو موردِ یافت‌شده اصلاح شد: نوار پیشرفت و ابزار گرد از ماژول
  صفحه به لایهٔ مشترک منتقل شدند.
- **کد مرده:** ۱۷ قاعدهٔ CSS بازمانده از قالب‌های پیشین حذف شد.

## ۵. محدودیت‌های شناخته‌شده

- اسکرین‌شات‌ها با دادهٔ fixture گرفته شده‌اند؛ گنجینهٔ عمومی در این داده پنج
  اثر دارد.
- `README.md` هنوز به ساختار قبلیِ ناوبری اشاره می‌کند.
